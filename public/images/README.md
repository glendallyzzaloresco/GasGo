# GasGo Images Directory

Place your images here.

## Logo
Replace `logo.png` with your actual GasGo logo file.
- Recommended size: 200px x 80px (or similar aspect ratio)
- Format: PNG with transparent background recommended
- The logo is used in:
  - Header navigation
  - Welcome/home page hero section
  - Loyalty card
  - Login page

## Current Placeholder
A placeholder SVG logo (`logo.svg`) has been created. You can use either:
- `logo.png` - Your actual logo image
- `logo.svg` - SVG format if available

To use your logo:
1. Save your logo image as `logo.png` in this folder
2. The views are configured to load `images/logo.png`
